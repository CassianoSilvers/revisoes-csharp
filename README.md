# Revisoes C#

Repositorio criado para praticar fundamentos de C# e registrar minha evolucao nos estudos.

## Projetos

### 01 - Calculadora

Calculadora de console desenvolvida em C#.

Funcionalidades:

- Somar dois numeros
- Subtrair dois numeros
- Multiplicar dois numeros
- Dividir dois numeros
- Validar entrada do usuario
- Impedir divisao por zero
- Repetir operacoes ate o usuario escolher sair

Conceitos praticados:

- Variaveis
- Metodos
- Estruturas condicionais
- `switch`
- `do while`
- `double.TryParse`
- Classes estaticas
- Separacao de responsabilidades
